# SAURIAN — 奔向荒野

使用 Three.js 制作的 3D 恐龙骑乘跑酷游戏。恐龙、骑手、地形植被、肖像和音效由代码生成；地表与岩壁采用随项目打包的 CC0 材质，无需运行时外部素材服务或 API 密钥。素材来源见 [CREDITS.md](./CREDITS.md)。

在线游玩：**[SAURIAN — 奔向荒野](https://ilikectrlmusic.github.io/dinosaur-game/)**

## 发布

推送到 `main` 后，GitHub Actions 会安装锁定版本的依赖、验证游戏规则、构建并发布到 GitHub Pages。发布流程见 `.github/workflows/pages.yml`。仓库的 Settings → Pages → Source 使用 **GitHub Actions**。

Vite 构建使用相对资源路径，因此游戏可在 GitHub Pages 的仓库子路径下直接运行。

## 运行

需要 Node.js 20.19+（或 22.12+）。

```sh
npm ci
npm run dev
```

开发服务器默认端口 5173。`npm run build` 生成 `dist/`，`npm run preview` 检查生产构建。

## 操作

| 按键                        | 操作                                   |
| --------------------------- | -------------------------------------- |
| Space / ↑ / W               | 跳跃                                   |
| 按住 ↓ / S                  | 伏低身体                               |
| V                           | 第一／第三人称视角                     |
| Esc / P                     | 暂停、继续                             |
| R                           | 重新出发                               |
| M                           | 音效开关                               |
| F                           | 全屏                                   |
| 鼠标左键拖动 / 手指拖动画面 | 环顾视角（第一人称转头，第三人称环绕） |
| 双击画面                    | 镜头回正                               |

游戏使用一条赛道，通过跳跃和低头躲避障碍。手机左下角整片区域可按住低头，右下角整片区域可轻触跳跃，圆形按钮作为位置提示；在画面上方拖动可围绕骑手转动视角。三位骑手外观不同；三种难度影响初速度、加速上限与障碍间隔。最佳距离按难度单独保存于浏览器。

手机游戏中的视角切换位于左上角里程面板下方。营地显示当前所选难度的 Personal Best；结束或从暂停返回营地时更新纪录。
营地介绍旁的「试玩原版」在新标签页打开 2D 版本。手机圆形按钮即时响应；扩大区域轻触起跳、停留长按低头、滑动转动视角，滑动结束不再触发点击或双击回正。
所有里程均直接显示实际数值，不补前导零；手机开局的跳跃、低头提示在画面中水平居中。

速度随存活时间逐渐提升，加速度随进程递减，达到对应难度的上限后保持。仙人掌有矮、中、高三种高度，均可通过起跳越过。150 米后开始出现翼龙：低飞的需要跳过，低头无效；高飞的只能按住低头从下方穿过，跳跃会撞上。300 米后会随机出现高低错落的三连仙人掌，需要一次越过整组。障碍间隔随提速缩短，三连组后另留出整组长度对应的恢复间隔；各难度解锁速度至最高速度均保留可行的起跳窗口。

每累计 1000 米，恐龙会张口喷火，里程数字同时轻闪。火焰、余烬、局部暖光和喷火音效用于里程庆祝，障碍仍需跳跃或低头躲避。喷火画面在暂停时冻结，重开和返回营地时清除。第一人称使用较窄、较淡的火焰以保留前方视野。

碰撞后使用 cannon-es 刚体、地面接触和受限关节模拟恐龙与骑手翻滚，保留碰撞瞬间的位置和动量。音效通过 Web Audio 实时合成，需用户首次点击后才能播放。模型为程序化平滑网格，不依赖外部 3D 资产。浏览器中未启用 WebGL 时会显示恢复说明。
仙人掌判定分别贴合主干和侧枝，骑乘方的范围随恐龙腿脚和腹部实际动画更新，并留出 2.5 厘米的向内容差；腾空收腿后不会继续按落地时的脚底高度判死。Safari 在触摸结束或点击后恢复音频，支持 playback 音频会话，旧版 iOS 使用本地静音媒体解锁；页面隐藏时暂停音频。

环境包括砂岩台地、天然拱门、龙舌兰、灌木、枯树和随风摆动的草丛，使用天空环境光和接触阴影。恐龙采用连续截面曲面、鳞片法线与皮肤色带，骑手的织物、皮革与装备细节在关节内合并绘制。流畅模式保留材质细节并降低草丛密度、关闭实时阴影与环境反射；以流畅模式启动时关闭多重采样抗锯齿。

第一方鳞片、织物和皮革贴图预先生成，避免 Safari 在启动时执行大量 Canvas 像素读回。需要重新生成时，先启动开发服务器，再运行 `node scripts/generate-surfaces.mjs`（使用 Chromium）；生成源码位于 `src/procedural-surfaces.js`。

山体、石柱和拱门按实际路程与赛道一起经过角色，并在远雾中循环衔接。缰绳使用端点固定的软绳模拟，随手掌和头部运动弯曲。两处开局提示在 5 秒后渐隐，重新出发时恢复。
仙人掌根部延伸进土中，路边仙人掌随移动和循环按实际地表三角形高度贴地。

Safari、浏览器标签页与 iPhone 主屏幕图标来自同一恐龙标志，使用带版本的 PNG、ICO、Apple 图标和独立 manifest，避免 SVG 支持差异及旧地址缓存；修改 `public/saurian-icon.svg` 后可运行 `node scripts/generate-icons.mjs` 重新生成 PNG 和 ICO。

## 验证

```sh
npm run build
npm test
```

默认测试使用 Chromium。读取 `CHROMIUM_PATH`，没有设置时尝试 `/usr/bin/chromium`；可安装 Playwright Chromium 后通过该变量指定路径。

手机 Safari 回归使用 Playwright WebKit：安装 `npx playwright install --with-deps webkit` 后运行 `npx playwright test --project=mobile-webkit`。如需指定已有的 WebKit 启动器，可设置 `WEBKIT_PATH`。测试覆盖单赛道、镜头居中、长按与触摸取消、提示布局与渐隐，以及连续死亡后重开、返回营地和动画异常恢复。Node 测试还验证山体循环连续性与缰绳动态连接。
